## Policy

This is a catalog, not a parent monorepo. Do not add primers as Git submodules
or copy their source here. Add each primer's remote URL and CI badge after it
is published, and keep its local path while this workspace remains useful.

See the sibling `primer-standards` repository for the shared maintenance
contract.
